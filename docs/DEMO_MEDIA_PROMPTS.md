# Demo media generation pack (Task 4.4)

How to use (docs/DEMO_MEDIA.md, sections 3 and 4):

- Generate each scene as a **16:9 landscape image, at least 1,280 px wide** (1,920 x 1,080 or larger preferred). Do not add any text or watermark: `prepare` adds the DEMO / CONCEPT mark.
- Keep every generator file unmodified in a sources folder outside the repository or in the excluded `.local/demo-media/sources` folder and record it in `demo/media/intake.csv`: `source_file`, `source_sha256`, the **actual** generator, model, date and the prompt as submitted, and the licence / terms reference you checked. Never invent these values.
- Prompts describe fictional scenes. An image never adds a listing fact; the "must not show" line lists unrecorded attributes to keep out of the image.
- Reject and regenerate images with people, legible text, logos, number plates, recognisable real buildings, warped geometry, or anything in "must not show".
